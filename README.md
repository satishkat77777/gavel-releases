# Gavel - Board Governance AI

Desktop client for Katy ISD Board of Trustees. Real-time governance assistant that monitors your screen and answers questions about board policy, meeting history, and TOMA compliance.

## Download

**[Download Latest Release (Windows x64)](https://github.com/satishkat77777/gavel-releases/releases/latest)**

Or download a specific version from the [Releases](https://github.com/satishkat77777/gavel-releases/releases) page.

## Installation

1. Download `Gavel-Setup-x.x.x.exe` from the latest release
2. Run the installer (one-click, no admin required)
3. Launch Gavel
4. Enter your `@katyisd.org` email and server URL
5. Connected - start asking questions

## Requirements

- Windows 10/11 (x64)
- Network access to the Gavel backend server
- A valid `@katyisd.org` email address

## Features

- Floating overlay that stays on top of all applications
- Screen-aware: understands what you're looking at
- Privacy mode: disable screen reading with one click
- Text-only queries when screen reading is off
- File attachment support (images, PDFs, documents)
- Follow-up suggestions based on context
- TOMA compliance checking
- Policy and statute search (355 meetings, 333 policies, 19k+ statute sections)

## Auto-Update

The application checks for updates automatically on every launch. When a new version is available, it downloads silently in the background and installs on the next restart. No action required.

## Troubleshooting

**SmartScreen warning on first install:**
Click "More info" then "Run anyway". The app is unsigned during the test phase.

**Cannot reach server:**
Open Settings (gear icon in panel header) and verify the server URL is correct.

**Registration screen keeps appearing:**
Click "Skip (already registered)" if you have previously connected.
